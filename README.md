
# Biblioteca Digital Java

Sistema de gerenciamento de biblioteca digital desenvolvido em Java.

## Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Listagem de livros e usuários
- Busca de livros por título
- Busca de livros por autor
- Busca de usuário por email
- Ordenação de livros por título
- Ordenação de livros por ano
- Empréstimo e devolução de livros
- Exceções personalizadas
- Streams e Lambdas
- Serialização e persistência em arquivos .dat
- Agrupamento de livros por autor

## Tecnologias

- Java
- Collections
- Streams
- Lambdas
- Comparable
- Comparator
- Exceptions
- Serialização
- Arquivos.
